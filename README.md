# refleksi-ppg

Website statis (HTML/CSS/JS) dengan tiga tab:

1. Semester 1: 6 mata kuliah
2. Semester 2: 5 mata kuliah (termasuk PPL Mandiri)
3. Refleksi Keseluruhan PPG

```
portofolio-refleksi/
├── index.html
├── styles.css
├── script.js
└── assets/img/hero.jpg   <- taruh foto hero di sini (opsional)
```

Buka index.html di browser, atau push ke GitHub dan aktifkan GitHub Pages.
Alamat langsung ke tab: index.html#semester-1, #semester-2, #refleksi-ppg
